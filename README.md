# 國立政治大學 - 作業二：傳統 NLP vs 現代 AI 文本處理方法比較

### 項目摘要
本項目旨在實作 TF-IDF、規則分類等傳統 NLP 技術，並與 GPT-4o 模型進行相同任務的實作與量化比較。目標是透過數據對比，理解兩代技術在速度、成本和語義理解上的核心差異。

#### 檔案說明：
本項目程式碼已作為單一 **Colab Notebook (.ipynb)** 檔案提交，所有 Part A, Part B 函式和執行邏輯均包含在此 Notebook 內。

### 執行環境與操作說明 (Colab 專用)

#### 1. 必要依賴與環境設定
本 Notebook 內部已包含所有依賴的安裝指令（例如 `jieba`, `openai`, `TCSP` 等）。請確保所有的 `!pip install` 和字體安裝指令已運行。

#### 2. API Key 設定 (關鍵步驟)
OpenAI API Key 必須透過 Colab Secrets 傳入。

1.  開啟此 Colab Notebook。
2.  點擊左側欄的「🔑 **Secrets** (密鑰)」圖標。
3.  新增密鑰，名稱必須設定為：`OPENAI_API_KEY`。
4.  將你的 OpenAI API Key 貼入值欄位。

#### 3. 運行步驟
請依照 Notebook 中的程式碼區塊**由上而下**順序執行所有任務：

1.  執行**環境設置與 Client 初始化**區塊。
2.  依序執行 **Part A-1, A-2, A-3** 的實作區塊 (傳統方法計算)。
3.  **執行 [額外加分 1] 詞雲視覺化**區塊 (運行時請注意中文字體安裝，並觀察詞雲圖輸出)。
4.  依序執行 **Part B-1, B-2, B-3** 的實作區塊 (現代 AI 呼叫)。
5.  執行 **Part C-1 量化比較運行**區塊 (獲取最終準確率和時間數據)。
6.  **執行 [額外加分 1] 詞雲圖視覺化、[額外加分 2] 效能優化 (快取)** 區塊 (觀察兩次呼叫的時間差異，驗證 `Cache Hit` 是否顯著快於 `API Call`)。
